How to run the application:

git clone the application into your backend folder, latest on main.
Setup a mysql database and make a connection according to the application properties file or make your own mysql connection.
Run BirdsApplication.java

git clone the frontend on https://git-iit.fh-joanneum.at/arneitzj15/ProjectWorkFrontend into your frontend folder, switch to deletefuncitonalities, latest edit is branch deletefuncitonalities
cd into birds folder
npm run dev
